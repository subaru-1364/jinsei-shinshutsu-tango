# 人生新出単語 仕様書・API管理規約

本ドキュメントは「人生新出単語」のシステム構成、機能要件、データ仕様、および外部API・セキュリティ管理方針を定義した仕様書です。

---

## 1. アプリケーション概要

- **名称**: 人生新出単語
- **用途**: 日常や読書の中で新しく出会った単語を記録し、書籍（ISBN）ごとの整理・辞書からの意味自動補完・重複なしランダムピックアップを行うWebアプリケーション。
- **特徴**:
  - Googleログイン必須によるPC・スマホ間のリアルタイムクラウド同期（Firebase Authentication / Realtime Database）
  - ISBN（13桁/10桁）からの書名・著者・表紙（書影）自動取得と書籍別シート管理
  - 国語辞典データ（Wiktionary / Wikipedia）からの意味自動付与と候補切り替え・確定機能
  - 全単語が一巡するまで同じ単語が重複しない「山札シャッフル方式」のランダムピックアップ

## 3. 外部API・APIキー管理・課金防止方針

本アプリは GitHub Pages（静的サイト）で公開されるため、**「課金が発生するAPIキーを一切持たない・埋め込まない」** 設計としています。

| 用途 | 使用API | APIキー | 課金・請求リスク | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **書名・著者・書影** | **Google Books API** (`volumes?q=isbn:...`) | **不要（未使用）** | **ゼロ（有料プラン自体が存在しない）** | 無料枠（1日1,000回/IP）超過時もエラーが返るだけで請求は一切発生しない |
| **書名・著者・書影** | **openBD API** (`api.openbd.jp`) | **不要** | **ゼロ（完全無料公開）** | 日本の出版業界による公開書誌・書影データ |
| **書影フォールバック** | **国立国会図書館 (NDL) サムネイル** | **不要** | **ゼロ（完全無料公開）** | 2024年刷新後の `ndlsearch.ndl.go.jp` エンドポイント（所蔵書影のみ） |
| **単語の意味取得** | **Wiktionary / Wikipedia API** | **不要** | **ゼロ（完全無料公開）** | ウィキメディア財団による無料公開API |
| **ログイン・同期** | **Firebase Auth / Realtime DB** | 公開識別子 (`firebaseConfig`) | **ゼロ（Spark無料プラン）** | クレジットカード未登録のSparkプランのため自動課金なし。DBルールで本人UIDのみ読み書き可能 |

## 4. 主要機能仕様

1. **ログイン必須ゲート**
   - 未ログイン状態ではログイン案内画面（`#login-gate`）のみを表示し、未ログイン時のローカル保存によるデータ不整合を防止。
2. **書籍（ISBN）別シート管理**
   - ISBNまたは書名で本棚タブを作成し、`edit.html` では選択中の本（または「未分類」）のシート単位で分割管理。
   - 内部データ形式は `# [BOOK:id|isbn|title|author]` セクションヘッダーにより1つの `bulkText` としてシリアライズされ、既存データとの100%互換性を維持。
3. **意味の自動付与と誤情報対策**
   - 意味なしで追加された単語に対し、Wiktionary（優先）およびWikipediaから意味候補を取得し `[自動]` ラベル付きで付与。
   - カード上でワンタップで「✓ この意味で確定」「別の候補」「意味だけ消す」を選択可能。
   - 意味を書かなくても分かる単語は「✓」ボタンで完了（意味ありタブ）へ移動可能（内部表記: `単語 : ✓`）。
4. **重複なしランダムピックアップ（山札方式）**
   - Fisher-Yatesシャッフルにより山札（`drawDeck`）を生成し、全単語が一巡するまで同じ単語が重複して出ない仕組み。
